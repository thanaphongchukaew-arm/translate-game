# Game Screen Translator

แอปเดสก์ท็อป Windows ที่จับภาพหน้าจอเกม อ่านข้อความด้วย OCR แปลเป็นภาษาไทย แล้ววาดคำแปลทับ/ข้างๆ ภาพเกมแบบเรียลไทม์ — **ฟรี 100% ทำงานออฟไลน์ทั้งหมด ไม่มีค่าใช้จ่ายตอนใช้งาน ไม่ส่งข้อมูลใดออกนอกเครื่อง**

## ภาพรวมการทำงาน

```
จับภาพหน้าจอ (dxcam/mss)
        │
        ▼
   OCR (RapidOCR, อังกฤษ→ไทย)
        │
        ▼
  รวมบรรทัด + ติดตามข้อความข้ามเฟรม
        │
        ▼
┌───────────────────────────────────────────┐
│ ชั้น 0: override/glossary/cache ผู้ใช้      │ ← ทันที
│ ชั้น 1: NLLB-200 (CTranslate2, แปลเร็ว)    │ ← ~45-80ms
│ ชั้น 2: LLM ปรับคำแปล (ทางเลือก, ยังไม่ตั้ง)│ ← ยังไม่เปิดใช้
└───────────────────────────────────────────┘
        │
        ▼
  แสดงผล: Overlay ทับเกม (A) / จอสองแสดงภาพแปล (B) / แผงคำแปล (C)
```

**สถานะปัจจุบัน**: ชั้น 1 (NLLB-200) ทำงานได้จริงและผ่านการทดสอบแล้ว ชั้น 2 (LLM ปรับคำแปล) เขียนโค้ดและทดสอบด้วยเซิร์ฟเวอร์จำลองแล้ว แต่ยังไม่ได้ติดตั้ง LLM จริง (ผู้ใช้เลือกข้ามไปก่อนเพราะชั้น 1 อย่างเดียวเร็วและแม่นยำพอ — ดูรายละเอียดใน `DECISIONS.md`)

## ความต้องการระบบ

- Windows 10 (build 19041 / 2004 ขึ้นไป) หรือ Windows 11
- Python 3.10–3.12
- แนะนำมี GPU (NVIDIA/AMD/Intel ที่รองรับ DirectX 12) เพื่อความเร็ว — ถ้าไม่มีจะถอยไปใช้ CPU อัตโนมัติ (ช้าลงแต่ยังใช้งานได้)
- พื้นที่ดิสก์ว่างอย่างน้อย ~1GB สำหรับโมเดล (ปัจจุบันใช้จริง ~650MB)

## การติดตั้ง

```powershell
git clone <repo> "game-translator"
cd "game-translator"
.\scripts\setup.ps1            # สร้าง venv + ติดตั้งไลบรารี + ตรวจฮาร์ดแวร์
.\scripts\download_models.ps1  # ดาวน์โหลดโมเดล (ครั้งเดียว, ต้องต่อเน็ต, ตรวจ hash อัตโนมัติ)
```

หลังจากนี้แอปทำงานได้โดย**ไม่ต้องต่ออินเทอร์เน็ตอีกเลย**

## การใช้งาน

```powershell
.\scripts\run.ps1
```

1. เปิดแอปแล้วเลือก **จอที่จะแปล** (จอที่เกมแสดงอยู่)
2. เลือก **โหมดแสดงผล**:
   - **A — Overlay ทับเกม**: วาดคำแปลทับตำแหน่งข้อความเดิมบนจอเกมโดยตรง (จอเดียว)
   - **B — จอสองแสดงภาพเกมแปล**: จอที่สองแสดงภาพเกมสดที่แทนข้อความด้วยภาษาไทยแล้ว (ต้องมี 2 จอ, **ค่าเริ่มต้นถ้ามี 2 จอ**)
   - **C — แผงคำแปลจอสอง**: จอที่สองแสดงรายการบทสนทนาที่แปลแล้วแบบเลื่อนขึ้น (เบาที่สุด)
3. กด **▶ เริ่มแปล** (หรือปล่อยให้เริ่มอัตโนมัติ — ค่าเริ่มต้น `autostart=true`)
4. แอปย่อลง system tray ได้ (กดปิดหน้าต่าง X จะซ่อนแทนที่จะปิดแอป) ปิดจริงผ่านเมนู tray → "ออกจากโปรแกรม"

### Hotkey

- `Ctrl+Alt+T` — เปิด/ปิด overlay ชั่วคราว
- `Ctrl+Alt+E` — เปิดตัวจัดการคำแปล

> **หมายเหตุ**: hotkey เขียนโค้ดตามสเปกแล้ว แต่ยังไม่ได้รับการยืนยันว่าทำงานบนทุกเครื่อง — ถ้ากดแล้วไม่มีอะไรเกิดขึ้น ให้ใช้ปุ่มในหน้าต่างควบคุมแทนไปก่อน

## การปรับปรุงคำแปลให้แม่นขึ้นเรื่อยๆ

กดปุ่ม **"จัดการคำแปล"** ในหน้าต่างควบคุมเพื่อ:
- **แก้คำแปล**: เลือกแถวในตาราง → กด "จำถาวร" → คำแปลนั้นจะใช้ทันทีทุกครั้งที่เจอข้อความเดิม (บันทึกลงดิสก์ ไม่หายแม้ปิดแอป)
- **เพิ่ม/แก้ glossary**: กำหนดคำแปลของคำศัพท์เฉพาะ (ชื่อไอเทม, ชื่อตัวละคร ฯลฯ) ที่โมเดลมักแปลผิด
- **ล้าง cache**: ล้างเฉพาะคำแปลที่ยังไม่ยืนยัน ไม่กระทบ override/glossary ที่บันทึกไว้

## ตั้งค่าเกมให้จับภาพได้ดีที่สุด

- ตั้งเกมเป็น **Borderless Windowed** (ไม่ใช่ Exclusive Fullscreen — โหมดนั้นจับภาพไม่ได้ จะเห็นเป็นจอดำ)
- ปิด HDR ถ้าสีภาพที่จับได้ดูซีดผิดปกติ

## ข้อจำกัดที่ต้องรู้ (พูดตรงๆ)

- **คุณภาพคำแปลต่ำกว่าบริการ AI คลาวด์ขนาดใหญ่** โดยเฉพาะข้อความ UI สั้นๆ 1-3 คำ (เช่น ชื่อเมนู) ที่โมเดลขนาดเล็กมักแปลแปลกๆ — ใช้ glossary ช่วยแก้ปัญหานี้ได้
- **Exclusive Fullscreen จับภาพไม่ได้** ต้องใช้ Borderless Windowed
- **overlay ไม่ถูกจับภาพโดยตั้งใจ** (กันไม่ให้ OCR อ่านคำแปลตัวเองวนซ้ำ) ผลคือ **ผู้ชมสตรีมผ่าน OBS/Discord จะไม่เห็น overlay** เว้นแต่ใช้โหมด window capture (WGC) ที่ยังไม่ได้ implement ในเวอร์ชันนี้
- **ระบบกันโกงของเกมออนไลน์**: แอปนี้ใช้แค่ Windows API มาตรฐานสำหรับจับภาพหน้าจอเท่านั้น (ไม่ inject โค้ด ไม่อ่านหน่วยความจำเกม ไม่จำลองอินพุต ไม่แก้ไฟล์เกม) **แต่ไม่รับประกันว่าจะไม่โดนตรวจจับหรือแบน** ผู้ใช้ต้องตรวจกฎของเกมด้วยตัวเองก่อนใช้กับเกมออนไลน์
- **ยังไม่มีเครื่องมือแก้ region แบบลากกรอบ (region editor) หรือ wizard สร้างโปรไฟล์อัตโนมัติ** — โปรไฟล์เกมต้องแก้ไฟล์ JSON ใน `profiles/` ด้วยมือในเวอร์ชันนี้

## ความเป็นส่วนตัว

ทุกอย่างประมวลผลในเครื่อง ภาพหน้าจอและข้อความที่ OCR อ่านได้**ไม่ถูกส่งออกนอกเครื่องเลย** ไม่มีการ log เนื้อหาข้อความที่ระดับ INFO (`log.log_text=false` เป็นค่าเริ่มต้น)

## การใช้ทรัพยากรเครื่อง

**ค่าเริ่มต้นคือโหมด "ทำงานตลอดเวลา"** — แอปวน OCR เต็มความเร็วไม่จำกัด fps และกิน GPU/CPU เต็มที่ตามการออกแบบ (ดู `DECISIONS.md` เฟส 3D) ถ้าเกมกระตุก ให้ปรับค่าใน `config.user.json`:
```json
{ "capture": { "max_ocr_fps": 8, "diff_threshold": 10 }, "resources": { "adaptive_throttle": true } }
```

## การแก้ปัญหาเบื้องต้น

| ปัญหา | วิธีแก้ |
|---|---|
| จับภาพได้จอดำ | เกมตั้งเป็น Exclusive Fullscreen อยู่ → เปลี่ยนเป็น Borderless Windowed |
| แปลช้ามาก | ตรวจว่า GPU provider ทำงานอยู่จริงด้วย `python tools\benchmark.py` |
| คำแปล UI สั้นๆ แปลกๆ | เพิ่มคำนั้นใน glossary ผ่านหน้าต่าง "จัดการคำแปล" |
| โมเดลหาย/เสีย | รัน `python tools\verify_models.py` แล้ว `.\scripts\download_models.ps1` ใหม่ |
| หน้าต่างควบคุมไม่ขึ้น | ตรวจว่ารันจาก terminal ของตัวเอง ไม่ใช่ผ่านเครื่องมืออัตโนมัติ (ดู `DECISIONS.md` เฟส 5 เรื่องข้อจำกัด window station) |

## โครงสร้างโปรเจกต์ / เอกสารเพิ่มเติม

- [`DECISIONS.md`](DECISIONS.md) — บันทึกการตัดสินใจ, บั๊กที่เจอและแก้, ผลทดสอบจริงทุกเฟส (ละเอียดมาก แนะนำอ่านถ้าอยากเข้าใจว่าอะไรทำงานจริง/ยังไม่ได้ทดสอบ)

- `tools/` — สคริปต์ตรวจสอบ/เบนช์มาร์ก (`benchmark.py`, `compat_check.py`, `bakeoff.py`, `verify_models.py`, `endurance_test.py`, `fps_impact.py`)
